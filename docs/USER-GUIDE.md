# 使用说明：让《皇牌空战 6》变成「日语语音 + 中文字幕」

> 这一份是给**玩家**看的，不讲原理，照着做就行。
> 想看技术细节、想自己动手改的，看 [README](../README.md)。

---

## 一、这个补丁是干什么的

《皇牌空战 6》在 PC 上用重编译版跑起来之后，语言只有一个开关，它同时管语音和字幕，所以只能二选一：

- 选英文 → 字幕是中文（汉化组的功劳），但**语音是英语**
- 选日文 → **语音是日语**，但字幕是日文

这个补丁把汉化组做好的中文资源，搬进了日文那一套里面。装完之后：

**语音是日语，字幕是中文，两个都要。**

---

## 二、你需要准备什么

| 东西 | 说明 |
|---|---|
| 一个能正常玩的 ac6_recomp 游戏 | 能进主菜单、能打第一关就行。如果你现在连游戏都跑不起来，先解决那个，这个补丁帮不上忙 |
| 我给你的补丁包 | 压缩包大约 **3 GB**，解压出来是 3 个文件 |
| 硬盘空间 | 补丁 3 GB + 备份 3 GB，**至少留 7 GB** |
| 解压软件 | 7-Zip 或 Bandizip。Windows 自带的解压遇到 3 GB 的包容易出错 |

游戏本体（`voicepack_jpn.bin`、`moviepack.bin` 这些几百 MB 的文件）**不用你准备**，你自己的游戏里已经有了，补丁不会碰它们。

## 三、补丁包里有什么

```
DATA.TBL        14 KB        索引表（告诉游戏每个资源在哪个位置）
DATA00.PAC      2.3 GB       资源包 A
DATA01.PAC      650 MB       资源包 B
使用说明.txt                  就是你正在看的这份
ac6recomp.toml  1 KB         配置文件（可选，见第四步）
```

只需要这 3 个文件（`DATA.TBL`、`DATA00.PAC`、`DATA01.PAC`）。**其他任何文件都不要覆盖**。

---

## 四、怎么装（5 步）

### 第 1 步：关掉游戏

任务管理器里确认 `ac6recomp.exe` 没有在跑。文件被占用会覆盖失败。

### 第 2 步：先备份

进入游戏目录下的 `assets` 文件夹，把这三个文件**改名**（不用复制，改名最省空间）：

```
DATA.TBL      →  DATA.TBL.bak
DATA00.PAC    →  DATA00.PAC.bak
DATA01.PAC    →  DATA01.PAC.bak
```

改完名字，原文件还在，随时能改回来。

### 第 3 步：覆盖

把补丁包里的 `DATA.TBL`、`DATA00.PAC`、`DATA01.PAC` 三个文件，**复制进 `assets` 文件夹**。

覆盖过程会比较慢（3 GB），等它复制完，别中途关窗口。

### 第 4 步：改配置文件（关键，别跳过）

游戏目录里有个 `ac6recomp.toml`，用记事本打开，确认里面有这三行，数值必须一样：

```toml
game_region   = 511
user_language = 1
user_country  = 103
```

没有就加上，数值不一样就改。**其他行别动**（那里面是你的分辨率和帧数设置）。

> 这三行是让游戏认为"我在日本"，这样日语语音才会出现。不改这一步，你只会得到中文字幕 + 英语语音。

### 第 5 步：启动，验证

双击 `ac6recomp.exe`，进游戏看三件事：

1. 主菜单是**中文** → 补丁生效了
2. 随便进一个任务，简报和无线电是**中文**、语音是**日语** → 成功了
3. 任务一的过场动画，字幕是**中文** → 成功了

## 五、装完发现不对？

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 一进游戏就黑屏 / 花屏 / 闪退 | 你的游戏本体资源和这个补丁不是同一个版本 | 换回备份，然后用**原版 ISO 重新解包**的 assets 再装一次 |
| 字幕是中文，但语音是英语 | 第 4 步没做，或者配置文件被游戏重置了 | 重新改 `ac6recomp.toml`，改完先别启动游戏去看一眼 |
| 语音和字幕对不上（说 A 显示 B） | `voicepack_jpn.bin` 版本和补丁不匹配 | 用原版 ISO 里的 `voicepack_jpn.bin` 替换 |
| 装完想反悔 | —— | 把 `.bak` 改回原名，删掉新文件即可，存档不受影响 |

**存档不在这三个文件里**，随便覆盖，不会丢档。

## 六、已知问题（必须提前告诉你）

**游戏里那几段"纯视频"动画，字幕还是日文。**

具体是这几处：

- 开场动画（汉化组 logo 播完之后那段）
- 第一关打完，紧接着那段带主要制作人员名单、像动漫片头曲一样的动画

这些不是游戏引擎画出来的字幕，而是**文字本来就烧在视频画面里**，等于视频的一部分。改资源文件完全碰不到它——我在游戏里试过了，改前改后画面一模一样。

汉化组多半是做过这段的，只是用的办法我们目前够不着；而且这些视频文件和原版逐字节相同，说明问题不在我们的补丁。要让它变中文，只能把视频拆出来、重新贴字幕、再压回去，工程量非常大，收益又只有两分钟片头，所以**不做了**。

好消息是这段完全不影响流程：不看就跳过，不影响剧情理解，也不影响进度。

除了这几段视频，其他部分全部正常：

| 内容 | 效果 |
|---|---|
| 菜单、UI | 中文 |
| 任务简报字幕 | 中文 |
| 无线电字幕 | 中文 |
| 任务内过场动画（实时渲染的） | 中文 |
| 开场动画 / 第一关后那段带名单的片头 | **日文，暂无解** |

如果你能接受这一点，那这个补丁对你就是完整的。

## 七、给分发者的打包清单

如果你想把打好的包转给别人，**只需要打这 3 个文件 + 一份说明**：

```
DATA.TBL
DATA00.PAC
DATA01.PAC
使用说明.txt
```

建议：

- 用 7-Zip 打包，压缩级别选「仅存储」，反正资源本来就是压缩过的，再压也省不了多少，还慢
- `ac6recomp.toml` 可以一起放进去，但要在说明里写清楚"只抄那三行，不要整个覆盖"，否则会盖掉别人的画质设置
- 压缩包名里带版本和日期，比如 `AC6_日语语音+中文字幕_v1_20261113.7z`，别人装错了你能一眼看出来
- 补丁包内含游戏资源，属于灰色地带，**公开发布时注意平台规则**，别直接放官方渠道
- 装过旧版的人，直接覆盖新版三个文件即可，不用先还原
